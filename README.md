# Chuletas — Desarrollo Web en Entorno Cliente (RA1–RA3)

Resumen de teoría y ejercicios para el examen de Entorno Cliente (2º DAW).

## Contenido

| Archivo | Descripción |
|---|---|
| `CHULETA-RA1-RA2-RA3.pdf` | Chuleta imprimible, 4 páginas A4 (2 hojas a doble cara). |
| `CHULETA-RA1-RA2-RA3.md` | Misma información en Markdown, editable. |

### Qué incluye

- **RA1**: modelo cliente-servidor, características de JavaScript, capas, arquitectura del navegador, criterios de clasificación, lenguajes y tecnologías.
- **RA2**: identificadores, `var`/`let`/`const`, hoisting, `typeof`, `==` vs `===`, strings y números.
- **RA3**: `Date`, `Math`, `Number`, métodos de `String`, `Array`, `Map`/`Set`, BOM, almacenamiento web, funciones, objetos y programación funcional.
- **Cuestionario RA3**: las 6 preguntas con respuesta correcta y explicación.
- **Ejercicios**: patrones de formularios, validaciones (DNI, IBAN, CCC, teléfono, matrícula, email), DOM, tablas dinámicas, clases, módulos y ejercicio tipo `CentroComercial`.
- **Trampas típicas**, tabla de métodos y salidas rápidas.

## Uso

Abrir el PDF e imprimir a doble cara. El Markdown sirve para ampliar o corregir contenido y regenerar el PDF.

## Aviso

Material de estudio personal. No sustituye los apuntes oficiales del módulo.
